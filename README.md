# Coffee Shop Website — Demo by Dinal Studios

**A complete, modern coffee shop website demo: hero section, filterable menu with prices, about section, opening hours with automatic "today" highlighting, and a working pickup-order form (front-end demo).**

Built as a single self-contained `index.html` — no frameworks, no build step, no external assets. Open it in any browser and it just works, on phone, tablet and desktop.

## Features

- Sticky responsive header with mobile hamburger menu
- Full-screen hero with call-to-action buttons and key highlights
- **Filterable menu with prices** — Coffee / Cold Drinks / Bakery tabs, rendered from a clean JavaScript data list (easy to edit prices and items)
- About / story section with feature list
- **Opening hours table** that automatically highlights the current day
- **Pickup order form** with item picker, quantity and live order-total confirmation message
- "Order a website like this" call-to-action linked to the Dinal Studios LaborX profile
- Fully responsive, mobile-first layout with modern CSS (grid, flexbox, gradients)
- Zero external dependencies — works offline as a plain file

## Tech Used

- HTML5 (semantic sections)
- CSS3 (custom properties, grid, flexbox, responsive media queries, SVG icons)
- Vanilla JavaScript (menu rendering, tab filtering, form handling, day highlighting)
